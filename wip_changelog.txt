CHANGELOG | JUST ZOOM v3.0.0 [ W I P !!! NOT PUBLIC YET !!! ]

- Completely reworked the Settings screen
  - Organized the Settings screen into General, Advanced, and Controls tabs
  - Improved the Settings screen's layout, scrolling, descriptions, terminology, and support for smaller window sizes
  - All Just Zoom keybinds can now be configured directly from the Settings screen, including mouse-wheel directions
  - Added individual reset buttons for every setting and keybind
- The settings can be opened through Mod Menu on Fabric and through the Mods menu on NeoForge
- Added a configurable keybind for opening the Settings screen (`B` by default)
- Added a one-time tutorial toast that explains how to open the Settings screen when zooming is first used
- Removed the icon button from the Pause screen that opened Just Zoom's Settings screen
- Changed the configuration format from `config.txt` to `config.json`
- Just Zoom now replaces the normal spyglass zoom logic with its own logic by default (can be disabled in settings)
- Added a setting to configure when the spyglass overlay should be visible: only while using a spyglass, only while using keybind zoom, during both, or never (default is "Only Spyglass")
- Added a setting to configure when spyglass sounds should play: only while using a spyglass, only while using keybind zoom, during both, or never (default is "Spyglass & Keybind Zoom")
- Spyglass sounds now also play when zooming with the normal zoom keybind by default
- Just Zoom now makes the spyglass work in third-person view when Spyglass Integration is enabled
- Added a setting to control when the HUD should remain visible while zooming: only while using a spyglass, only while using keybind zoom, during both, or never (default is "Never")
- It is now possible to zoom in significantly further than before
- Added a setting to adjust the maximum zoom factor (how far it is possible to zoom in) (#5)
- Base Zoom and Maximum Zoom are now percentage sliders
- Base Zoom and Maximum Zoom can now be previewed live in the world while adjusting their sliders
- Reworked zoom calculations around optical magnification, providing more consistent and symmetrical Zoom In/Out steps at different FOV values
- The last manually selected zoom level is now remembered across game restarts when "Reset Zoom" is disabled
- Added configurable keybinds for the Zoom In and Zoom Out actions (Mouse Wheel Up and Mouse Wheel Down by default)
- Added a "Zoom Step Size" setting for controlling the strength of each Zoom In or Zoom Out input
- Added a "Smooth Zoom Scroll Speed" setting for controlling how quickly smooth zooming reacts to Zoom In and Zoom Out inputs
- Improved the smooth zoom speed, responsiveness, and overall feel
- Zoom start and stop animations now have consistent durations regardless of the selected zoom level
- Added separate settings for configuring the start and stop zooming animation durations
- Improved mouse sensitivity normalization so camera movement remains proportional to the visible magnification
- It is now possible to turn off the improved third-person zoom that automatically switches to the first-person camera while zooming (#51, #43)
- Removed the "Allow Zoom in Mirrored View" setting; zooming is now always possible in mirrored view (#51)
- "Hide Hand" is now enabled by default
- Added homepage and issue-tracker links to the Fabric and NeoForge mod information screens
- Removed the incorrect "Library" badge from Just Zoom's Mod Menu entry
- Fixed the maximum zoom level being capped to the vanilla spyglass zoom level when smooth zooming was enabled
- Fixed the mod creating configuration folders in the system root when loaded server-side (#46)
- Fixed the "Hide Hand" setting not working when Iris shaders were enabled (#42)
